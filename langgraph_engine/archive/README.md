# Archived Development Scripts

The one-shot patch scripts (`fix_*.py`) in this directory were historical string-replacement patches used during early bootstrap development (Stages 1–3).

The architectural changes they introduced are already committed and integrated into `langgraph_engine/graph.py` and `langgraph_engine/preprocessor.py`.

These scripts must **NOT** be executed; they contain hardcoded obsolete paths and would corrupt active source files.
